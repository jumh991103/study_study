## 표준 모듈

1. **import** — 모듈 가져오기. `import math`처럼 쓰고, 사용할 때는 `math.cos()`처럼 모듈 안의 함수를 사용
2. **from 구문** — 함수 쓸 때 `math.cos()`처럼 함수 이름 앞에 `math` 같은 걸 붙이기 귀찮을 때 사용
   `from 모듈이름 import 가져오고싶은변수또는함수` (모듈 안의 함수·변수를 모두 쓰고 싶을 땐 `from 모듈이름 import *`)
3. **as 구문** — 모듈 가져올 때 이름 충돌이 있을 수 있음. 또는 모듈 이름이 너무 길 때 사용.
   `import 모듈 as 사용하고싶은식별자`

> 참고: 사용하는 모듈 이름과 같은 이름으로 파일을 저장하면 오류 발생

`sys`, `os`, `datetime`, `time`, `urllib` 모듈 예시 읽어보기 (강의자료 참고)

**많이 쓰는 모듈 함수** — `operator` 모듈의 `itemgetter()` 함수: 특정 dict가 모여있는 리스트에서 어떤 dict 내의 key 값을 빼내고 싶을 때 사용 가능

### 강의자료의 표준 모듈별 주요 함수 및 클래스

#### 1. collections

**Counter** — 시퀀스 자료형 데이터의 값의 개수를 딕셔너리 형태로 반환

```python
from collections import Counter
c = Counter(['a', 'a', 'b'])
c   # Counter({'a': 2, 'b': 1})
```

> ✅ **해결된 궁금증 — Counter는 이터레이터/제너레이터인가?**
> 아니, `Counter`는 딕셔너리를 상속받은 **클래스**임. 그냥 출력해보면 바로 값이 보임(`Counter({'a': 2, 'b': 1})`) — 이터레이터였다면 `<...object at 0x...>` 형태로 나왔을 것. 딕셔너리와 결정적으로 다른 점 하나: 딕셔너리는 없는 키에 접근하면 `KeyError`가 나는데, `Counter`는 없는 키를 조회해도 에러 없이 `0`을 돌려줌.
> ```python
> c['z']   # 0  (KeyError 안 남!)
> ```

- `Counter(시퀀스자료형).elements()` — **이터레이터**를 돌려줌 (딕셔너리 요소를 개수만큼 반복해서 하나씩 꺼낼 수 있게 해줌).
  ```python
  c = Counter(['a','a','b'])
  c.elements()          # <itertools.chain object at 0x...>
  list(c.elements())     # ['a', 'a', 'b']  ← list()로 감싸야 진짜 리스트가 됨
  ```
- `Counter(시퀀스자료형).most_common(숫자)` — 등장 횟수가 많은 순서대로 **상위 n개를 (요소, 개수) 튜플들의 리스트로** 돌려줌.
  ```python
  c = Counter(['a','a','a','b','b','c'])
  c.most_common(2)   # [('a', 3), ('b', 2)]
  ```
- `Counter`는 산술연산자 사용 가능

**OrderedDict**

> ✅ **해결된 궁금증 — OrderedDict가 뭔지**
> 딕셔너리인데, "넣은 순서를 기억하는 것에 특화된" 딕셔너리임. 사실 파이썬 3.7 이후부터는 일반 `dict`도 이미 순서를 기억해서, 요즘은 `OrderedDict`를 굳이 안 써도 되는 경우가 많음. 옛날 파이썬(3.6 이하)에서는 일반 `dict`가 순서를 보장 안 했어서, "순서가 중요하다"는 걸 명확히 하고 싶을 때 사용했던 것.
>
> `OrderedDict`가 일반 dict랑 다른 점 하나: **"두 딕셔너리가 같은지" 비교할 때 순서까지 고려함.**
> ```python
> from collections import OrderedDict
> a = OrderedDict([('x', 1), ('y', 2)])
> b = OrderedDict([('y', 2), ('x', 1)])
> a == b   # False! (순서가 다르니까)
>
> # 반면 일반 dict는
> {'x':1, 'y':2} == {'y':2, 'x':1}   # True (순서 상관없이 내용만 같으면 같다고 봄)
> ```

**defaultdict** — 딕셔너리는 없는 키에 접근하면 에러가 뜨는데, 이걸 보완 가능. 딕셔너리에 없는 키에 접근하면 지정한 기본값을 이용해서 key, value를 자동으로 생성해줌 (practice에서 연습 필요)

#### 2. random — 난수 발생 라이브러리

- `random.choice(시퀀스자료형)` — 시퀀스에서 1개의 원소를 무작위로 뽑음
- `random.choices(시퀀스자료형, weights=None, k=1)` — 시퀀스에서 중복 허용하여 k개를 뽑아 리스트로 반환. `weights`를 통해 가중치를 줄 수 있음.
  ```python
  random.choices(['a','b','c'], weights=[1,1,8], k=2)
  ```
- `random.sample(시퀀스자료형, k)` — 시퀀스에서 중복 없이 k개 뽑아 리스트로 반환. 가중치 없음.

> `choices`는 k가 시퀀스 자료형 길이보다 길어도 상관없는데(중복 허용이니까), `sample`은 길면 `ValueError` 남 (중복 없이 뽑아야 하는데 뽑을 게 모자라니까).
