## 표준 모듈
1. import - 모듈 가져오기 -> ex) import math , 사용할때는 math.cos()이런식으로 모듈안의 함수 사용
2. from 구문 - 함수 쓸떄 math.cos()이런식으로 함수이름 앞에 math같은거 붙이기 귀찮을떄 사용 -> from 모듈 이름 import 가져오고 싶은      
                변수또는함수(만약 math같은거 붙이긴 귀찮고 모듈내 함수 변수 모두 쓰고 싶을땐 from 모듈이름 import * 쓰면됨)
3. as 구문 - 모듈 가져올떄 이름 충돌있을 수 있음. 또는 모듈이름 너무 길때 사용. import 모듈 as 사용하고 싶은 식별자

참고) 사용하는 모듈이름과 같은 이름으로 파일을 저장하면 typeerror발생

sys,os,datetime,time,urlib 모듈 예시 읽어보기

많이 쓰는 모듈의 함수 -> operator 모듈의 itemgetter()함수 -> ex) 특정 dict가 모여있는 리스트에서 어떤 dict내의 key값을 빼내고 싶을때 사용가능

추가적으로 강사님 강의 자료의 표준 모듈들 별 주요 함수 및 클래스
1. collections
    1)Counter -> 시퀀스 자료형의 데이터의 값의 개수를 딕셔너리 형태로 반환(Counter클래스..?도 이터레이터인가?제너레이터인가?)
        -> Counter(시퀀스 자료형).elements() -> 딕셔너리의 요소들을 다시 리스트로 돌려줌.(맞는말인가..?)(이터레이터로 돌려주는건가??)
        -> Counter(시퀀스 자료형).most_common(숫자) -> 숫자만큼 큰 인자를 리턴해줌.
        -> Counter는 산술연산자 사용가능
    
    2)OrderedDict ->뭔지 모르겠음 설명 자세히 필요
    3)defaultdict -> 딕셔너리는 없는 키 접근하면 에러뜸. 이걸 보완가능 ->딕셔너리에 없는 키 접근하면 지정한 기본값을 이용해서 key,value 생성함.(practice에서 연습해봐)
2. random -> 난수 발생 라이브러리
    2.1) random.choice(시퀀스 자료형) ->시퀀스에서 1개의 원소를 무작위로 뽑음
    2.2) random.choices(시퀀스 자료형, weights =None, k=1) -> 시퀀스에서 중복허용하여 k개를 뽑아 리스트로 반환. weighs를 통해 가중치를  
         줄수있음. ex) random.choices(['a','b','c'], weights=[1,1,8], k=2)
    2.3) random.sample(시퀀스 자료형, k) -> 시퀀스에서 중복 없이 k개 뽑아 리스트로 반환. 가중치 없음.
    
    choices는 k가 시퀀스 자료형보다 길어도 상관없는데, sample은 길면 valueerror남. 

3. datetime (여긴 클래스 공부 하고 다시 오는게 좋을듯함. commit message에 적어두고 꼭 기억하자.혹시 까먹으면 클로드가 알려주겠지 클래스 공부 정리하는날 -> 강의자료의 라이브러리(시간),라이브러리(텍스트)이 두부분 공부하기.)
