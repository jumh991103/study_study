# 4장. 자료구조 정리 — 리스트, 튜플, 딕셔너리, 세트

## 리스트 (list)

1. 변경 -> `list이름[인덱스] = 바꿀값`

2. 요소 추가
   1) `list이름.append(요소)` -> 요소 하나만 추가 가능
   2) `list이름.insert(인덱스번호, 요소)` -> 어느 위치에 추가할지 지정 가능
   3) `list이름.extend(요소들)` -> extend는 인풋으로 받은 걸 하나씩 순회하면서 추가함.
      그래서 두 개의 문자를 추가하고 싶으면 `'hi'`처럼 넣으면 `'h'`, `'i'` 두 개가 각각 추가되고,
      list 형식으로 넣으면 그 list 안에 있는 것들을 하나씩 뽑아서 추가해줌

3. 요소 제거
   1) 인덱스로 제거하기
      - `del list명[인덱스]` -> `[::]`로 범위 지정해서 한꺼번에 삭제 가능
      - `list명.pop(인덱스)`
   2) 값으로 제거하기 -> `list명.remove(값)` -> 왼쪽부터 시작해서 가장 처음 만나는 그 값을 지움
   3) 모두 제거하기 -> `list명.clear()`

4. 요소 정렬 -> `list.sort()` -> `list.sort(reverse=True)`라고 하면 역순으로 정렬함

5. 내부에 요소 있는지 확인 -> `값 in list명`

6. 전개 연산자 -> `*리스트명` -> 리스트를 하나씩 풀어서 전개한 것과 같음.
   extend랑 다른 건, extend는 원본을 바꿔버리지만 얜 잠깐 풀어서 확인하는 정도임.
   그래서 `c=[*a]`를 해도 a의 요소들을 풀어서 c라는 리스트로 만든 것이지 a가 하나씩 풀린 건 아님

## 딕셔너리 (dict)

1. 요소에 접근 -> `dict이름[키]` -> 딕셔너리도 인덱스로 확인 가능하기 때문에 `[]`로 접근함

2. 요소 변경 -> `dict이름[가지고 있는 키] = 새로운 값`

3. 요소 추가 -> `dict이름[새로운 키] = 새로운 값`

4. 요소 제거 -> `del dict이름[키]`

5. 내부에 요소(키) 있는지 확인
   1) `키 in dict이름`
   2) `dict이름.get(키)` -> 존재하지 않으면 None 출력

6. 딕셔너리의 경우 for문을 사용할 때 딕셔너리의 요소 전부(키와 밸류값)가 모두 변수에 가는 게 아니라 **키만** 변수에 들어감 !!!! 중요

```python
dic = {"a": 1, "b": 2}
for k in dic:
    print(k)   # a, b  (키만 나옴)

# 키와 값을 둘 다 쓰고 싶으면 .items() 사용
for k, v in dic.items():
    print(k, v)   # a 1 / b 2
```

## 세트 (set)

1. 변경 -> ❌ 불가능. set은 "순서가 없는" 자료형이라 인덱스 자체가 없음. 그래서 특정 요소만 콕 집어서 바꾸는 방법이 없음

2. 요소 추가
   1) `set이름.add(요소)` -> 요소 하나만 추가 가능 (이미 있는 값이면 조용히 무시됨, 중복 불가라서)
   2) `set이름.update(요소들)` -> extend처럼, 인풋으로 받은 걸 하나씩 순회하면서 추가함.
      `update(['a','b'])`처럼 넣으면 `'a'`, `'b'` 각각 추가됨

3. 요소 제거
   1) `set이름.remove(값)` -> 그 값이 없으면 에러(`KeyError`) 남
   2) `set이름.discard(값)` -> 그 값이 없어도 에러 안 남 (더 안전한 버전)
   3) `set이름.clear()` -> 모두 제거

4. 요소 정렬 -> ❌ set 자체엔 정렬 메소드가 없음 (애초에 순서가 없는 자료형이라서).
   정렬된 결과가 필요하면 `sorted(set이름)`을 쓰면 리스트로 변환되어 나옴

5. 내부에 요소 있는지 확인 -> `값 in set이름`

6. 전개 연산자 -> `*set이름` -> 다른 것들과 마찬가지로 하나씩 풀어서 전개함.
   단, set은 순서가 없어서 풀리는 순서가 매번 보장되지 않을 수 있음

7. set만의 특별한 연산 (교집합/합집합/차집합)

```python
a = {1, 2, 3}
b = {2, 3, 4}

a & b   # 또는 a.intersection(b)   -> 교집합 {2, 3}
a | b   # 또는 a.union(b)          -> 합집합 {1, 2, 3, 4}
a - b   # 또는 a.difference(b)     -> 차집합 {1}
```

## 튜플 (tuple)

1. 변경 -> ❌ 불가능. 튜플은 "불변(immutable)" 자료형이라서 한 번 만들면 안의 값을 절대 못 바꿈

```python
t = (1, 2, 3)
t[0] = 10   # TypeError!
```

2. 요소 추가 -> ❌ 불가능. `append`, `insert`, `extend` 전부 없음 (불변이라서 애초에 "추가"라는 개념 자체가 성립 안 함)

3. 요소 제거 -> ❌ 불가능. `remove`, `pop`, `clear` 전부 없음 (같은 이유)

4. 요소 정렬 -> ❌ 튜플 자체엔 `sort()` 없음. 정렬된 결과가 필요하면 `sorted(tuple이름)`을 쓰면 리스트로 변환되어 나옴

5. 내부에 요소 있는지 확인 -> `값 in tuple이름` (조회만 하는 거라 가능)

6. 전개 연산자 -> `*tuple이름` -> 다른 것들과 마찬가지로 하나씩 풀어서 전개 가능 (조회 성격이라 가능)

7. 튜플은 뭘 할 수 있나 -> 조회(인덱싱/슬라이싱)만 가능

```python
t = (1, 2, 3, 4)
t[0]      # 1     -> 조회는 됨 (읽기는 가능, 쓰기만 안 됨)
t[0:2]     # (1, 2) -> 슬라이싱도 조회니까 가능
```

## 🔑 4개 자료형 한눈에 비교표

| | 리스트 | 튜플 | 딕셔너리 | 세트 |
|---|---|---|---|---|
| 순서 있음? | ✅ | ✅ | ✅ (파이썬 3.7+) | ❌ |
| 중복 허용? | ✅ | ✅ | 키는 ❌ / 값은 ✅ | ❌ |
| 변경 가능(mutable)? | ✅ | ❌ | ✅ | ✅ |
| 인덱스로 접근(`[0]`) | ✅ | ✅ | ❌ (키로 접근) | ❌ |
| 요소 추가 메소드 | `append`, `insert`, `extend` | 없음 | `dict[새키]=값` | `add`, `update` |
| 요소 제거 메소드 | `del`, `pop`, `remove`, `clear` | 없음 | `del` | `remove`, `discard`, `clear` |
| 정렬 | `.sort()` (원본 변경) | 없음 (`sorted()`만) | 없음 (`sorted()`만) | 없음 (`sorted()`만) |
| 만드는 기호 | `[ ]` | `( )` | `{ 키:값 }` | `{ 값 }` |

### 왜 이렇게 다르게 설계됐는지 (핵심 감각)

- **리스트**: 자주 바뀌는 순서 있는 데이터 → 뭐든 다 됨 (추가/삭제/변경/정렬)
- **튜플**: 절대 안 바뀌어야 하는 순서 있는 데이터 → 조회만 됨, 그 대신 가볍고 안전함
- **딕셔너리**: 키로 의미를 부여해서 찾아야 하는 데이터 → 인덱스 대신 키로 접근
- **세트**: 중복 없이 존재 여부만 중요한 데이터 → 순서·인덱스 개념 자체가 없고, 대신 교집합/합집합 같은 집합 연산이 특화됨

### for문 순회 시 차이

```python
# 리스트, 튜플은 for문 돌리면 값이 그대로 하나씩 나옴
for i in [1, 2, 3]:
    print(i)   # 1, 2, 3

for i in (1, 2, 3):
    print(i)   # 1, 2, 3

# 세트도 값이 하나씩 나오지만, 순서가 보장 안 됨
for i in {1, 2, 3}:
    print(i)   # 순서는 매번 같을 수도 다를 수도 있음

# 딕셔너리는 기본적으로 "키"만 나옴 (주의!)
for k in {"a": 1, "b": 2}:
    print(k)   # a, b
```
