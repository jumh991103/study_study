list,문자열,딕셔너리와 관련된 기본함수들
1. list내부의 최소 최대값 찾기 -> min(list이름), max(list이름) ->함수인데 list.min()이런식으로 안쓰는이유가 있나?그동안 list.append()이런식으로 썼잖아. 클로드야 그 이유를 여기 옆에 적어줘.
2. list내부 값 모두 더하기 -> sum(list이름)  -> sum,min,max를 쓸때는 list가 모두 숫자로만 이루어져있어야함.
3. list요소 순서 뒤집기  -> reversed(list이름) -> 이터레이터에서 자세히 설명하겠지만, 얘는 무조건 어떤 변수에 담아줘야 사용가능 ex) lst = reversed([1,2,3]) -> reversed함수는 제너레이터이기 때문에 뭔가 특별한 결과가 나옴.(예를 들어 reversed한 리스트를 반복문으로 리스트 요소를 뽑아냈을때 두번쨰 반복문에서 똑같이 리스트 요소를 뽑아내려하면 안나옴...여러번 사용이 안된다는 말인가? 뒷쪽에서 배운대)
4. list의 요소를 반복할때 현재 인덱스가 몇 번째인지 확인해야하는경우 -> list[enumerate(list이름)] 하면 [(인덱스번호, '요소').....]이런식으로 리스트안에 튜플형식으로 뽑힘. enumerate결과를 list안에 안넣으면 enumarate object at 0x02A43CB0이런식으로 뽑히던데 이거ㅔ 뭐지...reversed도 비슷하게 뽑히던데. ->이것도 이터레이터에서 배운대 -> for문돌릴때 enumerate쓰면 인덱스번호와 요소 두개가 나오므로 for a,b in enumerate(리스트)이런식으로 인자를 두개 둬야함.
5. dict에서 요소를 반복할때 enumarate처럼 쓸수있는 것 -> dict.items() -> 요것또한 키, 밸류값 두개가 나오므로 인자두개둬야함. 얘는 이너머레이트랑 달리 list안에 안넣어도 결과값이 나오는데 dict.items([(키,값),...]) 이런식으로 나오더라. 근데 for문에서 쓸때는 이너머레이트도 그렇고 얘도 그렇고 따로 리스트안넣어서 써도 되던데 신기하네.. ->앞에 배운내용으론 dict는 반복문에서 그냥사용하면 key만 뽑히던데 얜 두개다 뽑히네.
6. list comprehensions -> 리스트 이름 = [표현식 for 반복자 in 반복할 수 있는것 if 조건문] 요렇게 쓰면됨. 얘를 볼때 가독성이 떨어져서
리스트 이름 = [표현시
    for 반복자 in 반복할 수 있는것
    if 조건문
]이렇게도 쓴대. 궁금한건 if 조건문이 참일때만 for문이 실행되는건가. 순서를 모르겠네. 이것도 설명 옆에써줘 클로드야

7. 문자열.join(문자열로 구성된 리스트) -> 리스트의 요소를 문자열로 연결한다. 

8. 이터레이터에 대해 알아보자. for 반복자 in 반복할 수 있는 것 ->여기서 반복할수있는것을 프로그래밍 용어로 이터러블이라고 한다. 이터러블은 내부에 있는 요소들을 하나씩 꺼낼수있는 객첼르 의미한다.(리스트,튜플,문자열,딕셔너리 등등)
그리고 그 이터러블중에서 next()함수를 이용해서 하나씩 꺼낼수있는 요소를 이터레이터라고 한다.  이터레이터는 앞에서 봤던 것처럼 반복문의 매개변수로 전달할 수 있고, next(함수)로 내부의 요소를 하나하나 꺼낼수있음.그럼 왜 reversed같은 함수는 리스트를 안내보내주고 이터레이터를 내보내줌? 바로 메모리 효율성때문임... 어렵다.ㅇ
