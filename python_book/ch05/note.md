제너레이터
파이썬의 특수한 문법 구조.
이터레이터를 직접 만들떄 사용하는 함수임. 함수내부에 return대신 yield 키워드를 사용하면 그 함수는 제너레이터 함수가 되고, 함수 호출해도 내부 코드가 실행되지는 않음. 
그래서 next()함수를 사용해서 함수 내부 코드를 실행해주는데, 얘는 yeild키워드를 만나면 거기까지만 실행하고 yield키워드 뒤에 입력된 값을 출력함. 그리고 다시 실행하면 다음 yeild키워드까지 실행함. 그러다 next함수를 더 썼는데 yeild키워드가 없으면 stopiteration이라는 예외가 발생됨.
